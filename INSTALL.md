# Installing Slide Tools

The install guide lives in the manual: [Install Slide Tools](https://chadisfred.github.io/Slidetools/manual/install.html).

In short, for PowerPoint for Windows (Microsoft 365 or Office 2016 or later), with no admin rights needed:

1. Close PowerPoint.
2. Download and double click [Install-SlideTools.cmd](https://chadisfred.github.io/Slidetools/install/Install-SlideTools.cmd).
3. Open PowerPoint and click Slide Tools Panel at the right of the Home tab.

If you installed before version 2.25.0, run the installer once more to get the keyboard shortcuts.

The guide also covers manual install, uninstalling and troubleshooting.
