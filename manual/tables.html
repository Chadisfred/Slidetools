Tables

Format tables in one click, or insert a table that is already formatted.

Overview

Tables formats a table in one click using named table styles saved in the presentation, or inserts a table that is already formatted and sized to your grid.

Quick start

  1. Select a table: click its border or any cell.
  2. Check the column chips: Category, Label or Data.
  3. Click a style, or set rows and columns and click Insert table.

How it works

Column roles

RoleForAlignmentLines
CategoryStacked labels such as a year or team, shown once per groupLeftA line only where a group starts
LabelRow names that don't repeatLeftThin line under every row
DataNumbersRightThin line under every row, plus a vertical line on the left

The first guess: the first column is a Category. Text columns next to it that repeat or leave blanks are Categories too. Columns that are mostly numbers are Data. The rest are Labels. Total rows are ignored when guessing.

Fonts, fill and padding

  • The header row uses the header font, total rows the total font, the first column the first column font, and every other cell the body font.
  • The 2nd, 4th, 6th... columns, counted from the left edge, get the band fill in body rows.
  • Padding is the same on every side, except none on the first column's left and the last column's right, so text lines up with the table edges.
  • The header row sits at the bottom of its cells, body rows in the middle, and merged cells at the top.

Grid-based sizes

  • The table width is the Layout grid area width, rounded down to whole g.
  • Category and data columns are measured to fit their longest text in their font, plus padding, and rounded up to whole g.
  • Label columns share what is left, in whole g. With no label column, data columns share it.
  • Rows are set to 1g, then any row PowerPoint makes taller for wrapped text is rounded up to the next quarter of g.

Trimming spaces

Text pasted from Excel often has spaces before or after it, which change where text wraps and make columns look like they need more room. Before formatting, the spaces, tabs and line breaks at the start and end of each cell are removed. Spaces inside the text are kept. Only cells that actually change are rewritten, so untouched cells keep any formatting on part of their text. A cell that is trimmed can lose that kind of formatting, such as one italic word. Switch it off in the style editor, or use the Trim spaces button for a one-off clean up.

The line check

Some PowerPoint versions apply table line transparency the opposite way round, which hides the lines that should show and shows thin grey lines that should be hidden. The first time you format a table, the panel adds a small test table with cells A and B, each with a thick line underneath set the opposite way, and asks which one you can see. The answer is remembered on this computer, and the test table is deleted.

Finding the table

The table can be selected by its border, or with the cursor in a cell. Tables inside content placeholders (made with the table icon in a layout) are found too. If no shape is selected, the panel uses the table it last saw on the slide, or the only table on the slide.

Sending the formatting

Lines, fill, fonts, padding and alignment are sent to PowerPoint as separate groups. If PowerPoint refuses one, the rest still apply, and the message names the refused group.

Recipes

Format every table in a deck the same way

Consistent tables everywhere.

  1. Select a table and check its chips.
  2. Click the style.
  3. Repeat for each table, or run Update all later to refresh every linked table.

Clean up a table pasted from Excel

Pasted numbers and labels that wrap oddly or make columns too wide.

  1. Paste the cells from Excel into the slide, so PowerPoint makes a table.
  2. Select the table and click Trim spaces.
  3. Check the column chips, then click the style. Column widths now fit the real text.

Build a grouped budget table

Year and team groups with totals.

  1. Insert a table with enough rows, or paste one from Excel.
  2. Fill in Year, Team, Item and Cost, writing labels on every row.
  3. Add rows starting with Total where needed.
  4. Click Stack repeats, then the style.

Change the house table style

A new band colour or font everywhere.

  1. At More, click the pencil on the style.
  2. Change the settings and click Save.
  3. Click Update all.

Make tables line up with the grid

Tables that fit the grid area in steps of g.

  1. Use Arrange, Guides, Use in Layout so g matches your template.
  2. Check Grid-based sizes is on in the style.
  3. Reapply the style.

Limits and edge cases

  • Inserting needs PowerPoint API 1.8. Formatting an existing table needs 1.9.
  • Only the top left cell of a merged area can be formatted.
  • The table keeps its position. Only its width and row heights change.
  • Fonts must be installed on the computer, or PowerPoint substitutes another.
  • If the columns need more room than the grid area, the table is wider and the message says so.
