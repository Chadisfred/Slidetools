Elements

Prebuilt design elements in your theme colours.

Overview

Elements drops prebuilt design elements onto the slide: a stat card with a value and an arrow, a pointer card with bands joined by small pointers, and a big number. They use your theme's colours and fonts, so they match the template they're placed in.

Quick start

  1. Click the picture of the element you want, then pick a colour and fill in its text.
  2. Draw a rectangle where it should go and select it.
  3. Click Place element, then edit the text on the slide like any other shape.

How it works

One group, text inside

Each element is a group. Every band is a shape that holds its own text, so the text moves with its band. Bullets have a hanging indent, so wrapped lines line up under the text.

Theme colours

Colours are theme colours with PowerPoint's own lighter and darker variants, and fonts are the theme's heading and body fonts.

TipBands don't grow on their own when you add a lot of text. Make a band taller and move the ones below it, or place the element again with more height.
