Corners

Give rounded rectangles an exact corner radius.

Overview

Corners gives rounded rectangles an exact corner radius in points, so boxes of different sizes share the same corner.

Quick start

  1. Select rounded rectangles.
  2. Type the radius in points, or pick a preset at Full.
  3. Click Round selection.

How it works

PowerPoint stores a rounded rectangle's corner as a fraction of its shorter side, so the same setting looks different on shapes of different sizes. Corners converts your radius in points into that fraction for each shape: radius / shorter side, capped at half.

TipThe cap means a radius larger than half the shorter side turns the shape into a pill. That is the roundest a rounded rectangle can be.

Recipes

Make every card on a slide match

Consistent corners across different sized cards.

  1. Select all the cards.
  2. Type the radius, for example 8.
  3. Press Enter.

Copy a corner from an existing shape

Use a shape that already looks right as the reference.

  1. Switch Corners to Full.
  2. Select the reference shape and click Read radius from selection.
  3. Select the other shapes and click Round selection.

Limits and edge cases

  • Only rounded rectangles have a corner radius to set. Square rectangles can't be converted from the panel. Draw them as rounded rectangles, or use Layout with Draw with rounded corners.
  • Shapes inside groups aren't changed. Ungroup first.
  • Needs PowerPoint API 1.10.
