Expert tips

How experienced users combine the tools and keep decks consistent.

Set up a new template once

  1. Grid, More, Snap, Guides, Use for grid: g, left and top now match the template.
  2. In Grid, set the area width and height to the content area, or select the content placeholder and click Use selection as area. Save it as a preset.
  3. Build text styles (Heading, Body, Label) with Sample.
  4. Build shape styles for cards and callouts, each with a text style.
  5. Add brand colours on the Colours Yours tab.
  6. Check the Default table style matches the house style, and run Check lines once.
TipStyles, shape styles, table styles and colours are saved in the presentation. Set them up in the template file and every deck made from it starts ready.

Combining tools

GoalTools, in order
A tidy multi-column slideGrid Draw, then Shape styles, then Styles for the text.
Clean up an inherited slideGrid Snap with Guides, then Size with col formulas, then Select similar to restyle similar shapes.
The same element on every slidePosition Copy, then Paste on each slide, then Select similar Next slide to check.
Consistent tablesGrid Use for grid, then Tables with grid-based sizes, then Update all after style edits.
A deck-wide font changeEdit the text style, then Update all. Shape styles carrying that text style follow.

Keyboard shortcuts

These work while the slide has focus, so click the slide first. On a Mac, use Cmd+Option+Shift instead. They need PowerPoint for Windows 2601 or later, PowerPoint for Mac 16.105.2 or later, or PowerPoint on the web, and the 2.25.0 install (run the installer again once if you installed before). The list is also in the panel's settings menu, under Keyboard shortcuts.

ActionKeys
Nudge left, up, down, rightCtrl+Alt+Shift+Left and the other arrows
Wider, narrower, taller, shorterCtrl+Alt+Shift+L, J, I, K
Repeat last actionCtrl+Alt+Shift+D
TipNudge and the size keys step by the Nudge by amount in Position, and sizes change around the reference point in Size. The size keys I, J, K and L are laid out like the arrow keys. To repeat a copy you dragged with the mouse, use PowerPoint's own Ctrl+D: duplicate, drag the copy into place, and each further Ctrl+D uses the same offset. Repeat last action repeats panel actions only. If another add-in uses the same keys, PowerPoint asks once which one to run.

Work faster

  • Press Enter in Size's Width or Height to apply just that side, in Corners' radius to round, and in Position's gap to place shapes across.
  • Use Tab to move between boxes.
  • Pin the two tools you use together, such as Size and Position, so both stay open.
  • Drag a tool by its dots to move its button nearer the start of the grid.
  • Keep tools at Basic day to day, and switch to More only when you need the extra options.
  • Hide tools you never use from the settings button.
  • Click a recent formula in Size (Full) instead of retyping it.

Keep a deck consistent over time

  • Style through the panel, not the ribbon, so items stay linked.
  • Recolour styled text from the Colours tool, which keeps the link.
  • Before sending a deck, run Update all in Styles, Shape styles and Tables. If nothing is edited, it reports everything is up to date.
  • Use Select similar to find stray shapes that look like a style but aren't linked.

Precision habits

  • Type 30pt rather than 0.42 when your template uses a 30 pt grid.
  • Use Even gaps when the outer shapes must not move, and Across or Down when the gap must be exact.
  • Use Snap all four edges for widths that land exactly on guides.
  • Read the guide report under Snap in Grid to spot template guides that are slightly off.
