Shape styles

Save a shape's look as a reusable style and update it everywhere.

Overview

Shape styles saves a shape's look as a named style: fill, outline, corners, text box margins and alignment, and optionally a text style for the text inside.

Quick start

  1. Select a shape and click Sample.
  2. Name it and click Save style.
  3. Select other shapes and click the style.

How it works

Linking

A linked shape carries a tag with its style's number. Recolouring the shape never breaks the link, unlike text styles.

Hand changes and Update all

Update all compares each linked shape with both the style's current settings and the settings from the last update. Anything you changed by hand since then is kept. Everything else is updated.

Lookalikes

A shape that isn't linked but has the same fill and outline (type, colour, weight and dash) as a style is offered as a lookalike, with the choices leave, apply the style, or apply it and keep the shape's colours.

Recipes

Create a card style

A reusable card look.

  1. Format one shape as a card: fill, no outline, 8 pt corners, margins.
  2. Select it and click Sample, name it Card, and pick a text style for its text.
  3. Save, then apply Card to other shapes.

Update every card in the deck

A colour or corner change everywhere.

  1. Edit Card and change the fill colour.
  2. Click Update all and review.
  3. Click Update.

Limits and edge cases

  • Gradients, pictures, shadows and other effects can't be set by add-ins.
  • Corner radius only applies to rounded rectangles.
  • Shapes inside groups are included in Update all with PowerPoint API 1.8.
  • Masters and layouts are never changed.
