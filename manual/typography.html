Typography

Font, size, style and exact text spacing, margins and autofit, with grid formulas.

Overview

Typography sets the font, size, style and case of text, exact character spacing, line spacing, paragraph spacing, kerning and baseline, plus text box margins, autofit and wrapping.

Quick start

  1. Select text, or shapes with text. The live preview shows the first shape.
  2. Pick a font or type a size such as 2g and press Enter. Font settings apply straight away.
  3. Fill in only the spacing you want to change, such as Line spacing 0.9 Lines and Space after 6, and watch the preview.
  4. Click Apply spacing.

How it works

Which text changes

Font, size, style and case change the highlighted text when you have highlighted some, and all the text in the selected shapes otherwise. Spacing always applies to all the text in each shape.

Points and the grid

Every points box takes formulas, with the grid names in points: g is the grid spacing (a 0.41667 in grid is 30 pt), and col, row, gap and vgap work too. Units convert to points, so 1cm is 28.35 pt. Lines and Baseline % take plain numbers.

You typeWith a 30 pt grid
2g in Size60 pt text
g/2 in a margin15 pt margin
g in Line spacing (Points)Lines 30 pt apart, on the grid
+2 in SizeEach text 2 pt larger than it is now

Applying

Font settings, margins, autofit and wrapping use PowerPoint's add-in API and apply straight away. PowerPoint add-ins can't set character spacing, line spacing, paragraph spacing, kerning or baseline, so for those the slide is exported, the text settings are written to that copy in memory, and the copy replaces the slide. Nothing is sent anywhere, and only the slide itself changes, never the master or layouts.

TipSlide comments may not carry over to the replaced slide, and Undo takes more than one step. Typography asks first, unless you chose Don't ask again.

Recipes

Text sized to the grid

Headings and body text that step with your layout.

  1. Select the heading and type 2g in Size, then press Enter.
  2. Select the body text and type g/2, then press Enter.
  3. Set Line spacing to g/2 Points for body lines that sit on the grid.

Tight headlines

Large headings that don't look loose.

  1. Select the headings.
  2. Set Character spacing to -0.5 and Line spacing to 0.9 Lines.
  3. Click Apply spacing.

Text that lines up across columns

Body text in several boxes on the same baseline grid.

  1. Select the text boxes.
  2. Set Line spacing to 18 Points, and Space before and after to 0.
  3. Click Apply spacing, then set the same top margin in all of them.

Copy settings from one box to others

Match a box that already looks right.

  1. Switch Typography to More and select the box.
  2. Click Read from selection.
  3. Select the other boxes and click Apply spacing and Apply margins.

Limits and edge cases

  • Spacing applies to all the text in each selected shape, not to a highlighted part of it.
  • Text in tables, charts and groups isn't changed.
  • Font, size, B, I, U, margins, autofit and wrapping need PowerPoint API 1.4. Highlighted text needs 1.5. Case and spacing need 1.8.
  • A font picked here is set by name. PowerPoint's own Theme Fonts entries are the way to keep text linked to the theme.
