Typography

Exact text spacing, margins and autofit.

Overview

Typography sets exact character spacing, line spacing, paragraph spacing, kerning and baseline, plus text box margins, autofit and wrapping, for the selected shapes.

Quick start

  1. Select shapes with text. The live preview shows the first one.
  2. Fill in only the spacing you want to change, such as Line spacing 0.9 Lines and Space after 6, and watch the preview.
  3. Click Apply spacing.

How it works

Margins, autofit and wrapping use PowerPoint's add-in API and apply straight away. PowerPoint add-ins can't set character spacing, line spacing, paragraph spacing, kerning or baseline, so for those the slide is exported, the text settings are written to that copy in memory, and the copy replaces the slide. Nothing is sent anywhere, and only the slide itself changes, never the master or layouts.

TipSlide comments may not carry over to the replaced slide, and Undo takes more than one step. Typography asks first, unless you chose Don't ask again.

Recipes

Tight headlines

Large headings that don't look loose.

  1. Select the headings.
  2. Set Character spacing to -0.5 and Line spacing to 0.9 Lines.
  3. Click Apply spacing.

Text that lines up across columns

Body text in several boxes on the same baseline grid.

  1. Select the text boxes.
  2. Set Line spacing to 18 Points, and Space before and after to 0.
  3. Click Apply spacing, then set the same top margin in all of them.

Copy settings from one box to others

Match a box that already looks right.

  1. Switch Typography to More and select the box.
  2. Click Read from selection.
  3. Select the other boxes and click Apply spacing and Apply margins.

Limits and edge cases

  • Spacing applies to all the text in each selected shape, not to a highlighted part of it.
  • Text in tables, charts and groups isn't changed.
  • Spacing needs PowerPoint API 1.8. Margins, autofit and wrapping need 1.4.
