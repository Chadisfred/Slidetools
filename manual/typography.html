Typography

Font, size, style and case, margins and autofit, with grid formulas.

Overview

Typography sets the font, size, style and case of text, plus text box margins, autofit and wrapping. Every change shows on the slide straight away.

Quick start

  1. Select text, or shapes with text.
  2. Pick a font, or type a size such as 2g and press Enter.
  3. Click B, I or U, or a Case button. The slide changes straight away.

How it works

Which text changes

Font, size, style and case change the highlighted text when you have highlighted some, and all the text in the selected shapes otherwise. Margins, autofit and wrapping apply to each selected shape.

Points and the grid

Size and the margin boxes take formulas, with the grid names in points: g is the grid spacing (a 0.41667 in grid is 30 pt), and col, row, gap and vgap work too. Units convert to points, so 1cm is 28.35 pt.

You typeWith a 30 pt grid
2g in Size60 pt text
g/2 in a margin15 pt margin
+2 in SizeEach text 2 pt larger than it is now

Spacing

PowerPoint add-ins can't set line spacing, character spacing or space before and after directly. Use Paragraph and Font on PowerPoint's Home tab for those, so you see the result on the slide as you change it.

Recipes

Text sized to the grid

Headings and body text that step with your layout.

  1. Select the heading and type 2g in Size, then press Enter.
  2. Select the body text and type g/2, then press Enter.

Copy margins from one box to others

Match a box that already looks right.

  1. Switch Typography to More and select the box.
  2. Click Read from selection.
  3. Select the other boxes and click Apply margins.

Limits and edge cases

  • Text in tables, charts and groups isn't changed.
  • Font, size, B, I, U, margins, autofit and wrapping need PowerPoint API 1.4. Highlighted text needs 1.5. Case needs 1.8.
  • A font picked here is set by name. PowerPoint's own Theme Fonts entries are the way to keep text linked to the theme.
