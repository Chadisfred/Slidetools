Install Slide Tools

Add the Slide Tools panel to PowerPoint for Windows in about a minute, without admin rights.

What you need

  • PowerPoint for Windows, from Microsoft 365 or Office 2016 or later.
  • An internet connection. The panel loads from the web each time PowerPoint opens it.
  • No admin rights. Everything installs for your Windows account only.

Quick install

The installer is the easiest way and is the one to try first.

  1. Close PowerPoint.
  2. Download the installer: Install-SlideTools.cmd.
  3. Open your Downloads folder and double click Install-SlideTools.cmd. If your browser says the file isn't commonly downloaded, choose Keep. If Windows shows "Windows protected your PC", click More info, then Run anyway.
  4. A window opens, installs Slide Tools and says when it's done. Press any key to close it.
  5. Open PowerPoint. Click Grid Panel on the Home tab, in the Slide Panel group.
No button?If the button isn't on the Home tab, go to Home, Add-ins, then My Add-ins, and pick Slide Tools from there.

What the installer changes

  • It saves the add-in's install file in a Slidetools folder in your user folder.
  • It adds one PowerPoint setting that points to that file.

Leave that folder where it is, because PowerPoint reads the file from there.

Manual install

Use this if the installer is blocked on your PC.

  1. Close PowerPoint.
  2. Press Windows + R, type %USERPROFILE% and press Enter. Make a new folder there called Slidetools.
  3. Open slidetools-manifest.xml in your browser. Press Ctrl + S and save it in the new Slidetools folder, keeping the name slidetools-manifest.xml.
  4. Press Windows + R, type cmd and press Enter. Paste this line into the black window and press Enter:
    reg add "HKCU\Software\Microsoft\Office\16.0\WEF\Developer" /v SlideTools /t REG_SZ /d "%USERPROFILE%\Slidetools\slidetools-manifest.xml" /f
    It should say "The operation completed successfully."
  5. Open PowerPoint and look for Grid Panel on the Home tab.

Updates

There's nothing to do. Slide Tools updates itself, and restarting PowerPoint picks up the latest version.

Uninstall

Close PowerPoint, then download and double click Uninstall-SlideTools.cmd.

Or remove it by hand. Run this line in a command window, then delete the Slidetools folder in your user folder:

reg delete "HKCU\Software\Microsoft\Office\16.0\WEF\Developer" /v SlideTools /f

Troubleshooting

ProblemWhat to try
No Grid Panel buttonCheck Home, Add-ins, My Add-ins. If it isn't there either, close PowerPoint completely, including any PowerPoint entries in Task Manager, and open it again.
The panel shows an old versionClose PowerPoint. Press Windows + R, paste %LOCALAPPDATA%\Microsoft\Office\16.0\Wef, press Enter, delete everything in that folder, and reopen PowerPoint.
The panel is blank or shows an errorCheck that the panel's web address opens in your browser, then reopen the panel.
The installer can't download the fileA network filter may block it. Use the manual install steps.
A message says add-ins are blocked by your organisationYour IT team controls add-ins. Ask them to deploy slidetools-manifest.xml from the Microsoft 365 admin center, under Integrated apps.
A button says PowerPoint is too oldUpdate Office from File, Account, Update Options.
