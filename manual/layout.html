Grid

Plan a grid of columns and rows, draw it on the slide, fit shapes into it, and snap shapes to it or to your template's guides.

Overview

Grid works out a grid of columns and rows inside an area of the slide, then draws it as shapes, fits existing shapes into it, or snaps shapes onto it or onto your template's guides. Its grid spacing, g, is also the measuring stick for Position, Size and Copies formulas, and Tables.

Quick start

  1. Pick a preset such as Thirds, or set Columns and Rows.
  2. Switch the tool to More and check the preview and cell size.
  3. Click Draw on slide, or select shapes and click Fit selection or Snap.

How it works

The grid maths

Everything is worked out from five numbers: the area width and height, g, and the two gap fractions.

  • Gap between columns = g x the column fraction. Gap between rows = g x the row fraction. None is a fraction of 0, so cells touch.
  • Column width = (area width - gaps) / columns. With Golden or Sidebar, the space is split by their ratios instead of equally.
  • Row height = (area height - gaps) / rows.
  • With a ratio, the space left after the gaps is shared out by the parts instead. 2:1:1 in 12.08 in gives 6.04, 3.02 and 3.02 in.
  • The grid is valid when every cell has a width and height above zero.

Worked example with the defaults: g = 0.42 in and a gap of 1/2 gives 0.21 in gaps. Five columns in 12.5 in leave 12.5 - 4 x 0.21 = 11.66 in, so each column is 2.332 in.

Names other tools can use

The grid is published to formulas: g is the spacing, col the first column's width, row the row height, gap and vgap the gaps. See Formulas and units.

Drawing and fitting

  • Draw adds plain rectangles with the theme's default look, so you can restyle them with Shape styles or Colours.
  • Fit sorts the selected shapes by their top edge, takes them a row at a time (as many as there are columns), and sorts each row by its left edge. Each shape then takes the position and size of its cell.
  • Both work on the slide you are on. Masters and layouts are never changed.

Snap rules

  • Snap always moves the top left corner to the nearest line, both across and down.
  • Columns: the lines are each column's left edge and each row's top edge. With Resize to the cells it covers, the right and bottom edges move to the nearest column and row ends.
  • Steps: the lines are every g from the grid area's top left, in both directions.
  • Guides: the lines are the guides themselves. Vertical guides for left and right, horizontal guides for top and bottom.

Where guides come from

PowerPoint keeps guides in two places: presentation guides, which you can drag on any slide (templates usually bring these), and template guides in the slide master or layout, which are locked outside Slide Master view. Snap reads a copy of the open file, so it finds both. Nothing in the file is changed.

The guide report

Guide positions are stored to the nearest eighth of a point. The report finds the most common spacing, then lists any guide sitting a little off that pattern (within a point or 10% of the spacing) and by how much. Guides far off the pattern, such as a centre line, are treated as deliberate.

Why shapes drift off guidesPowerPoint shows guide positions rounded to two decimals, so a 30 pt grid (0.41667 in) looks like 0.42. If you type 0.42 as g, shapes drift further from the guides across the slide. Use for grid copies the exact value.

What is remembered

All Grid values and your presets are saved on this computer and come back next time you open the panel, in any presentation.

Recipes

A three column agenda slide

Three equal boxes that line up with the rest of your deck.

  1. Click the Thirds preset.
  2. At More, check Area width and height match your content area, or select the content placeholder and click Use selection as area.
  3. Click Draw on slide.
  4. With the three boxes still selected, click a style in Shape styles to give them your card look.

A 2 x 2 grid of cards

Four equal cards with matching gaps across and down.

  1. Set Columns to 2 and Rows to 2.
  2. At More, set both gaps to the same fraction, for example 1/2.
  3. At Full, turn on Draw with rounded corners and set the radius in Corners first if you want rounded cards.
  4. Click Draw on slide.

A wide feature column with two narrow ones

One column twice the width of the others.

  1. At More, type 2:1:1 in Column ratio. Columns changes to 3.
  2. Check the cell sizes under the preview.
  3. Click Draw on slide, or select three shapes and click Fit selection.

Butt cards edge to edge

A strip of cells with no space between them, such as a process bar or a table like band.

  1. Set Columns and Rows.
  2. At More, click None in Gap between columns, and in Gap between rows if you have more than one row.
  3. Click Draw on slide. Each cell starts exactly where the one before it ends.

Rebuild an untidy slide onto the grid

Existing shapes that roughly form columns, snapped into an exact grid.

  1. Set Columns and Rows to match the shapes, for example 3 columns and 2 rows.
  2. Select all the shapes.
  3. Click Fit selection. Each shape moves into its cell in reading order.
  4. If a shape lands in the wrong cell, nudge it so it sits more clearly in its row, and fit again.

Match the grid to your template's guides

Make g exactly the spacing of your template's guides.

  1. Under Snap, choose Guides.
  2. Switch Grid to More and click Use for grid.
  3. The grid spacing, left and top now match the guides to five decimal places.

Fix shapes drifting off the guides

Shapes that look slightly off the template guides, more so on the right.

  1. Choose Guides under Snap in Grid.
  2. Switch Grid to More and read the guide report. Note any guide marked slightly off.
  3. Click Use for grid so g matches the guides exactly.
  4. Select the shapes and click Snap.

Snap a whole slide to the template

Every shape on the slide sitting on a guide.

  1. Select all with Ctrl+A.
  2. Choose Guides, and at More turn on Snap all four edges for exact widths.
  3. Click Snap.

Limits and edge cases

  • Up to 12 columns and 8 rows.
  • Golden and Sidebar ratios only apply with 2 columns. With any other number of columns, columns are equal.
  • Fit selection needs at least as many cells as selected shapes.
  • Grouping after drawing needs PowerPoint API 1.8, and exact rounded corners need API 1.10. Without them the shapes are still drawn.
  • Selecting shapes after drawing needs API 1.5.
