Styles

Save text formatting as reusable styles and change it everywhere at once.

Overview

Styles saves text formatting as named character styles inside the presentation. Apply them with one click, and change every piece of text that uses a style with Update all.

Quick start

  1. Select text and click Sample.
  2. Name it and click Save style.
  3. Select other text and click the style.

How it works

How text stays linked

Each style has a number from 1 to 63. When a style is applied, that number is hidden in the tiniest bits of the text colour, shifting it by at most 3 out of 255 per colour channel, which you can't see. The text box is also tagged with the styles it uses. Text counts as linked only when the hidden number, the tag and the colour all agree.

Local changes

If you change a linked piece of text by hand, for example making one word italic, it stays linked and shows a +. Update all keeps those hand changes and updates everything else.

Lookalikes

Recolouring text from PowerPoint's ribbon replaces the hidden number, so the link breaks. Update all finds text that still matches a style (same font and size settings) and offers three choices: leave it, apply the style and its colour, or apply the style but keep the text's own colour. You can choose per style or item by item, and click an item to see it on its slide.

Recolour without breaking linksColouring styled text from the Colours tool keeps the link and records the new colour as a local change.

Update all, step by step

  1. Every normal slide is read. Masters and layouts are skipped.
  2. Text is split into runs of identical formatting.
  3. Each run is classed as linked, lookalike or unrelated.
  4. The review lists, per style, how many linked pieces will update and how many lookalikes were found.
  5. Clicking Update writes the changes. Undo in PowerPoint reverses them.

Where things are saved

Styles are saved inside the presentation, so they travel with the file. The font check result (whether installed fonts can be listed) is remembered on this computer for about 12 hours.

Recipes

Set up Heading, Body and Label styles

A small set of styles for a new deck.

  1. Format one heading the way you want, select it, click Sample, name it Heading and save.
  2. Do the same for body text and a small label.
  3. Select the other headings across slides and click Heading.

Change the font across the whole deck

A font or size change everywhere a style is used.

  1. Click the pencil on the style and change the font or size.
  2. Click Save changes. The style shows Edited.
  3. Click Update all, check the review, and click Update.

Rescue text recoloured from the ribbon

Relink text whose link broke, keeping its new colour.

  1. Select the text. The status says Looks like Heading (colour changed).
  2. Click Relink, keep colour.
  3. For many at once, use Update all and choose Apply style, keep their colour.

Limits and edge cases

  • Character settings only: font, size, colour, bold, italic, underline, strikethrough, caps and position. PowerPoint add-ins can't set paragraph spacing, line spacing or kerning.
  • Colours are fixed hex colours, not theme colours.
  • Tables aren't scanned by Update all. Use the Tables tool for table text.
  • Masters and layouts are never changed.
  • Strikethrough, caps and position need PowerPoint API 1.8, as does Update all inside groups.
