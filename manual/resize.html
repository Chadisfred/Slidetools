Transform

Set exact sizes with grid formulas, and make spaced copies in one step.

Overview

Transform sets exact sizes with numbers or formulas based on your grid, so shapes are exactly a number of columns wide or a number of grid steps tall.

Quick start

  1. Select one or more shapes.
  2. Type a width or height, such as 2col+gap.
  3. Press Enter or click Resize.

How it works

Formulas

Each box is worked out for each selected shape separately, so w and h mean that shape's own size. The result is in inches, unless you add a unit such as pt.

You typeResult
33 inches
72pt1 inch
2col+gapTwo Layout columns plus the gap between them
10gTen grid steps
*2Double the current size
w/2Half the current width
row-gOne row height minus one grid step

Reference point

The chosen point keeps its position. For example, with Right, the right edge stays put and the shape grows or shrinks to the left. With Centre, the shape changes size evenly around its middle.

Lock aspect ratio

The new height is worked out as current height x new width / current width, so each shape keeps its own proportions.

Lines

A line is resized by its length, whichever box you type in. The length is measured end to end, so a diagonal line 3 in across and 4 in down is 5 in long. Width and height change by the same factor, so horizontal lines stay horizontal, vertical lines stay vertical, and diagonal lines keep their angle and direction. In formulas, w and h both mean the line's length, so *2 doubles it. Largest and Smallest match lines to each other by length, and match other shapes in the same selection by size.

Cropping pictures

When a picture's new frame has the same proportions as before, it simply scales. When the proportions change, the picture keeps its scale and the reference point stays still, so the frame shows more or less of the picture, like dragging PowerPoint's crop handles. If the frame would run past the picture's edges, the picture grows just enough to cover it. The picture is never stretched and never shows blank edges.

PowerPoint add-ins can't crop a picture directly, so Transform exports the current slide, sets the new crop and frame in its copy, inserts that copy straight after the original using the deck's own layout, and removes the original. All of this happens in memory inside the panel: nothing is sent over the internet and nothing is stored. Only the slide is changed. Masters and layouts are never edited. The result is an ordinary picture you can recrop with PowerPoint's own Crop tool.

  • Slide comments may not carry over to the copy.
  • Undo takes more than one step, because the slide was swapped.
  • Pictures inside groups are left alone.
  • It needs PowerPoint API 1.8. Without it, pictures keep their proportions and you're told why.

Copies

Copies work like Illustrator's Transform effect. One set of values is applied to the original to make copy 1, then applied again to copy 1 to make copy 2, and so on. Each step runs in this order, around the reference point of the shape it starts from:

  1. Scale the width and height by the percentages, keeping the reference point still.
  2. Reflect across the reference point, if Reflect X or Y is on.
  3. Rotate around the reference point. Positive is counterclockwise.
  4. Move by the Move values (Distance), or place the copy that far past the previous one's edge (Gap).

Values are worked out from each selected shape's own size, so w+gap spaces wide and narrow shapes correctly in one go. Text size and line weight never scale, the same as Illustrator with Scale Strokes and Effects off.

PowerPoint add-ins can't copy shapes, so copies use the same slide swap as cropping: the slide is exported, exact copies are added to that copy (text, formatting, pictures, groups, tables and charts), and it replaces the original. It all happens in memory in the panel, and only the slide is changed.

  • Copies get new ids and names, such as Card copy 1, and sit just above their original.
  • A copy of a placeholder becomes an ordinary shape at the same place, so it no longer follows the layout. Text formatting that came from the layout may look different.
  • Copied connectors are no longer attached to the shapes they joined.
  • Tables, charts and other frames can't rotate or flip, so those settings are skipped for them. Tables also keep their size, because it comes from their rows and columns.
  • Slide comments may not carry over, and Undo takes more than one step.

Recipes

Make cards span exact columns

Shapes exactly two columns wide, lined up with the grid.

  1. Set up the grid in Layout.
  2. Select the shapes.
  3. Type 2col+gap in Width and press Enter.
  4. Use Arrange to snap them onto the columns.

A row of evenly spaced cards

Four identical cards one grid gap apart, in one step.

  1. Make and style one card, and select it.
  2. Set Copies to 3 and Move across to w+gap. Leave Move down empty.
  3. Click Make copies.

A ladder of steps

Boxes that step down and across, like a staircase.

  1. Select the first box.
  2. Set Copies to 4, Move across to w+gap and Move down to h+vgap.
  3. Click Make copies.

A ring of shapes

Shapes swung evenly around a point.

  1. Select the shape. The ring's centre will be its bottom middle, so a taller shape gives a wider ring.
  2. At More, set the reference point to the bottom middle.
  3. Clear both Move boxes, set Copies to 7 and Rotate to 45.
  4. Click Make copies. Eight shapes now sit evenly around the ring.

Mirror a shape

A mirror image right beside the original.

  1. Select the shape.
  2. At Full, set the reference point to the right middle and turn on Reflect Y.
  3. Clear both Move boxes and set Copies to 1.
  4. Click Make copies.

Make a row of icons the same size

Icons of different sizes made identical.

  1. Select the icons.
  2. Switch Transform to More and set the reference point to Centre.
  3. Click Largest or Smallest.

Fit a photo into a grid cell

A photo cropped to exactly one cell, with nothing stretched.

  1. Select the photo.
  2. At More, check Crop pictures to fit is on and set the reference point to Centre.
  3. Type col in Width and row in Height, then click Resize.
  4. Use Arrange to snap it into the cell.

Make all dividers the same length

Horizontal and vertical rules that match exactly.

  1. Select the lines.
  2. Type the length in Width, for example 4col+3gap, and press Enter. Vertical lines stay vertical.
  3. Or click Largest to match them all to the longest one.

Scale a picture without stretching it

Change one side and keep the proportions.

  1. Select the picture.
  2. At More, turn on Lock aspect ratio.
  3. Type the width you want and press Enter.

Copy one shape's size to others

Several shapes made the same size as a reference shape.

  1. Select the reference shape and click Use selection.
  2. Select the other shapes.
  3. Click Resize.

Limits and edge cases

  • A formula must work out to more than zero, or nothing changes.
  • Formulas are worked out for the whole selection first. If one shape's result is invalid, nothing is resized.
  • Resizing needs PowerPoint API 1.5.
