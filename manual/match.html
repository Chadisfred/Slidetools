Select similar

Select shapes like the one you pick, on this slide or slide by slide.

Overview

Select similar finds shapes that look like the one you pick, on this slide and through the deck.

Quick start

  1. Select an example shape.
  2. Choose what to match.
  3. Click Select similar on slide. Switch to More and use Next slide to keep going.

How it works

Matching

  • The example's details are read once, when you click Select similar. Next and Previous compare every slide's shapes against that example, using the chips that are on at that moment.
  • Fill colour compares the fill type and exact colour. Shape style and Text style compare the styles linked by the Shape styles and Styles tools.
  • Pictures, tables and groups can only match by Type and Size.

Stepping through the deck

PowerPoint can only select shapes on one slide at a time, so Next slide moves to the next slide that has matches and selects them there. The count tells you how many slides are left to visit.

Recipes

Restyle every callout in the deck

Change all shapes of one look at once, slide by slide.

  1. Select one callout and leave Fill colour and Type on.
  2. Click Select similar on slide, then click a style in Shape styles.
  3. Click Next slide and apply the style again. Repeat until the count reaches the end.

Limits and edge cases

  • Only shapes directly on a slide are matched, not shapes inside groups.
  • Masters and layouts are never searched.
  • Selecting shapes needs PowerPoint API 1.5.
